# The Bayesian Way

*The Bayesian Way* is a Bayesian Statistics textbook intended for students of Statistics, data science, mathematics, and related fields, as well as graduate students interested in developing a deeper understanding of this approach to statistical inference. Readers are assumed to be familiar with the fundamental concepts of frequentist statistics and regression analysis and to have basic knowledge of a programming language such as R or Python.

The book seeks to maintain a balance among theory, computational implementation, and practical application. It begins with the foundations of Bayesian Statistics and gradually progresses toward more sophisticated models and methods.

Throughout the chapters, examples and applications based on real-world cases are presented alongside detailed explanations and reproducible code. All code used in the sections, examples, and applied exercises is openly available in this repository.

The book and datasets can be downloaded free of charge from [this link](https://sites.google.com/view/juansosa/the-bayesian-way).

The R code used in all sections and examples of the book are freely available in this repository.
